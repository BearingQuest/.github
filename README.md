# BearingQuest/.github

This repository holds the BearingQuest organization profile, `profile/README.md`, which
GitHub shows on https://github.com/BearingQuest.

Keep everything else out. GitHub treats some files in a public `.github` repository
(for example `SECURITY.md`, `CONTRIBUTING.md`, issue and pull request templates) as
defaults for every repository in the organization that doesn't have its own copy.
Add one only on purpose, after a decision is recorded.

The two lockup SVGs in `profile/` are unedited copies of the Bearing Quest design-system
files (the same bytes as `assets/img/` in BearingQuest/bearingquest.github.io).
